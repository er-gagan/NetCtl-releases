# NetCtl releases

This repository publishes Windows installers for NetCtl. The application source code is private and is not stored here.

## Install

1. Open the [latest release](https://github.com/er-gagan/NetCtl-releases/releases/latest).
2. Download the NetCtl Setup installer.
3. Run it. Windows may show a SmartScreen warning because the package is not code-signed. Choose More info, then Run anyway.
4. For speed limits, site blocking, and safe browsing, start NetCtl as Administrator.

## Updates

The installed app checks for a new release once each time you open it. It does not check again while it stays open. If a newer version exists, NetCtl downloads it in the background and installs it when you close the app. The next time you open NetCtl, the new version is running.
